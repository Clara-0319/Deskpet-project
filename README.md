# 🐱 Deskpet-project

一个基于Java的桌面小宠物程序，为你的电脑桌面带来可爱的虚拟宠物陪伴。

![Language](https://img.shields.io/badge/Language-Java%2099.6%25%20%7C%20CSS%200.4%25-blue)
![License](https://img.shields.io/badge/License-MIT-green)

## ✨ 功能特性

- 🎨 **可爱的UI界面** - 使用Java Swing框架打造流畅的用户界面
- 🎮 **交互式体验** - 与你的虚拟宠物互动，享受娱乐时刻
- 📊 **宠物数据管理** - 跟踪宠物的状态（饱食度、开心度等）
- ⚙️ **轻量级应用** - 占用资源少，不影响日常工作
- 🎯 **简单易用** - 开箱即用，无需复杂配置

## 🚀 快速开始

### 系统要求

- Java 8 或更高版本
- 操作系统：Windows / macOS / Linux

### 安装方式

1. **克隆仓库**
   ```bash
   git clone https://github.com/Clara-0319/Deskpet-project.git
   cd Deskpet-project
   ```

2. **编译项目**
   ```bash
   # 使用Maven
   mvn clean compile
   
   # 或使用Gradle
   gradle build
   ```

3. **运行程序**
   ```bash
   # 使用Maven
   mvn exec:java
   
   # 或直接运行JAR文件
   java -jar target/deskpet.jar
   ```

## 🎮 使用方法

1. 启动应用程序后，你的宠物会出现在屏幕上
2. 点击宠物进行互动（喂食、玩耍等）
3. 观看宠物的日常动画和反应
4. 保持宠物的健康和开心状态
